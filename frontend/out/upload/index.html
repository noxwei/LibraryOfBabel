Processing notes

  • Extraction, chunking, and ingestion happen immediately after upload.
  • Embedding is queued for background processing via the overnight daemon.
  • Books become searchable once embedding completes.
  • Supported format: EPUB only (no PDF, MOBI, etc.)
  • Maximum file size: 100 MB per EPUB.
