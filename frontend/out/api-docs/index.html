API Reference

Integrate LibraryOfBabel's semantic search into your applications

Authentication

Most endpoints require an API key passed via the X-API-Key request header. Health check endpoints are publicly accessible without authentication.

curl -H "X-API-Key: your_api_key_here" \
  https://api.example.com/api/books?action=list

Health & System

Server health and system status endpoints. No authentication required.

GET/api/health

Full system health check including database, embeddings, and API status. No authentication required.

GET/health

Simple health ping. Returns 200 if the server is running. No authentication required.

Books

Browse, list, and read books in the library.

GET/api/books?action=list

List books in the library with pagination, sorting, and genre filtering.

GET/api/books?action=summary&id={id}

Get detailed metadata and summary for a specific book.

GET/api/books?action=toc&id={id}

Get the table of contents for a book, including chapter titles and page numbers.

GET/api/books?action=page&id={id}&page={n}

Read a specific page of a book. Returns the page content with navigation links.

Search

Full-text and AI-powered semantic search across all books and passages.

GET/api/search?action=search&q={query}

Basic full-text search across all books. Returns matching passages with relevance scores.

GET/api/search?action=semantic_passages&q={query}

AI-powered semantic search using embedding models. Finds conceptually similar passages even without exact keyword matches.

GET/api/search?action=count&q={query}

Get the number of search results for a query without returning the full results.

GET/api/search?action=books&q={query}

Search for books by title or metadata. Returns book-level results rather than individual passages.

Mobile / Shortcuts

Lightweight endpoints optimized for mobile apps and quick lookups.

GET/api/mobile/random?type=title

Get a random book title from the library. Useful for discovery features and "I'm Feeling Lucky" flows.

GET/api/mobile/stats?type=count

Get total book count in the library. Lightweight endpoint for dashboards and status displays.

GET/api/mobile/search?q={query}&action=count

Mobile-optimized search count. Returns just the number of matching results for a query.
