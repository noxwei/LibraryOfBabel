Seven modes of inquiry

The library can be approached in different ways. Each mode reflects a different relationship to the text — none is privileged over another.

i. hermeneutic

Meaning

Semantic search. You have an idea — find where it resonates across 4,945 books.

ii. referential

Reference

Keyword search. You know the word, the title, the author — find the exact match.

iii. analytic

Analysis

Cross-corpus patterns. Trace influence, map style, track how themes evolve.

iv. exegetic

Reading

Navigate the stacks. Browse the catalog, read page by page.

v. synthetic

Synthesis

Ask a question. The library retrieves passages and composes an answer.

vi. aleatory

Discovery

Random pages, random titles. Designed for serendipity, not directed search.

vii. instrumental

Instrument

The system itself. Health, architecture, MCP integration, EPUB upload.

What’s in the library

The collection spans philosophy, literature, science, history, technology, and more. Every book is chunked into passages, embedded with vector models, and indexed for semantic search.

How it works

Books are uploaded as EPUBs, split into ~250-word passages, and embedded using multiple vector models. Search queries are embedded in real time via a local Ollama instance, then matched against 2.36 million passage vectors using PostgreSQL + pgvector with HNSW indexing. The entire system runs on a Mac Mini.

Embedding models

Each passage is embedded by multiple models. Search uses nomic-embed-text-v2-moe as the primary model.

nomic-embed-text-v2-moe — 768d, 96.4% coverage (primary)
bge-m3 — 1024d, 90.2% coverage
gemini-embedding-001 — 768d, 47.8% coverage
